# db/ — өгөгдлийн сангийн харагдац ба нийтийн эрхийн хил

Аппын ажиллагаанд шаардлагатай Postgres обьектуудын **эх бичиг**. VPS дээр байгаа
зүйлийн хуулбар — репод байх шалтгаан нь:

- VPS дахин байгуулбал **дүрэм алга болно**. Нөөц хуулбарт ямар SQL байсныг хэн ч
  мэдэхгүй.
- Өөрчлөгдсөн түүх git-д үлдэнэ (VPS дээр үлдэхгүй).
- Шинэ агент «нийтэд юу нээлттэй вэ» гэдгийг эндээс уншиж мэднэ.

⚠ Эдгээр файл **автоматаар хэрэгждэггүй.** Гараар ажиллуулна. Файл ба амьд
байдал зөрж болно — тиймээс амьд ЗАН ҮЙЛИЙГ өдөр тутмын харуул шалгадаг:
`tools/contract-check.js` (`.github/workflows/contract-watch.yml`).

## Файлууд

| Файл | Юу вэ | Ажиллуулах шаардлага |
|---|---|---|
| `public_availability.sql` | Нөөц эзэлж байгаа захиалга (сайт сул үлдэгдэл бодоход) | Аппын `_ORDER_OCCUPYING` өөрчлөгдвөл **ЗЭРЭГ** |
| `anon-grants.sql` | Нийтийн (anon) эрхийн хил — юу нээлттэй, юу хаалттай | Дахин ажиллуулах шаардлагагүй (одоогийн байдлын баримт) |

Сайтын харагдацууд (`public_catalog`, `app_config_public`) нь
`m-event-website-ready/db/`-д — тэднийг сайт л уншдаг.

## Ажиллуулах

```bash
ssh chimun-vps 'docker exec -i vps-deploy-postgres-1 psql -U chimun -d chimun -v ON_ERROR_STOP=1' < db/public_availability.sql
```

## Хамгийн чухал дүрэм

**`app.js`-ийн `_ORDER_OCCUPYING` ба `public_availability.sql`-ийн төлвийн
жагсаалт ЯГ ИЖИЛ байх ёстой.** Зөрвөл апп ба mevent.mn өөр сул үлдэгдэл
харуулж, давхар захиалга үүснэ. `test/run.js`-д SCAN-тест бий — хоёр жагсаалт
зөрвөл CI унана. Аль нэгийг өөрчлөх = хоёуланг зэрэг өөрчлөх.

2026-09-10 хүртэл `installing` (хүргэсэн, суурилуулж байгаа) ба `teardown`
(буулгасан, агуулахад ирээгүй) хоёр орхигдсон байсан — суурилуулалттай захиалга
бүрд давхар захиалгын 2 цонх нээгдэж байв.

## Аюулгүй байдлын хил

PostgREST-д **JWT байхгүй хүсэлт `anon` үүрэг болдог**. Өөрөөр хэлбэл сайтын
түлхүүрийг солих нь юуг ч засахгүй — anon-д нээлттэй бүх зүйл интернэтээс
уншигдана. `anon-grants.sql` тэр хилийг бүтнээр бичсэн.

**Шинэ хүснэгтийг anon-д БҮҮ нээ.** Сайт үнэхээр уншдаг эсэхийг кодоор шалга;
уншдаг бол харагдац үүсгээд түүнийг нээ, хүснэгтийг БИШ. Харагдац эзнийхээ
эрхээр ажилладаг тул үндсэн хүснэгт хаалттай байсан ч ажиллана.
